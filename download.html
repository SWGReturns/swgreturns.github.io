Getting started

Installation Instructions

Choose your galaxy below. You need Windows 10 or 11, enough free storage for the extracted client, and a legal copy of Star Wars Galaxies.

Core3 Pre-CU

  1. Download SWGReturns_Core3_Installer.zip above and extract the installer EXE.
  2. Run SWGReturns_Core3_Installer.exe, choose an install folder, and leave it open while the approximately 9 GB client downloads and extracts.
  3. When installation completes, use the new SWGReturns Core3 desktop shortcut.
  4. For resolution, windowed mode, graphics, or sound changes, open Core3 Graphics Setup from the SWGReturns Start-menu folder.
  5. You can still install the shared SWGReturns launcher for future scanning and patch updates.

NGE / JTL

  1. Download SWGReturns_NGE_Installer.zip above and extract the installer EXE.
  2. Run SWGReturns_NGE_Installer.exe, choose an install folder, and leave it open while the approximately 8 GB existing NGE client downloads and extracts.
  3. When installation completes, use the new SWGReturns NGE - JTL desktop shortcut.
  4. For resolution, graphics, or sound changes, open NGE Graphics Setup from the SWGReturns Start-menu folder.
  5. You can still use the shared SWGReturns launcher for future NGE scanning and patch updates.
Having trouble? Keep the game outside protected folders where possible, add the chosen game folder to your antivirus exceptions if files are quarantined, and never mix Core3 and NGE files in the same folder. You can rerun the appropriate setup EXE whenever you need to change resolution, windowed mode, graphics, or sound. For help, use the contact page or community Discord.
