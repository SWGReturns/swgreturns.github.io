Install Guide

Step-by-step instructions to get started on the SWGReturns galaxy — from downloading the launcher to your first login.

💻 System Requirements

  • OS: Windows 10 / 11 (64-bit)
  • RAM: 4 GB minimum, 8 GB recommended
  • Storage: 10 GB free space
  • GPU: DirectX 9.0c compatible
  • Network: Broadband internet connection
  • SWG Client: A legal copy of Star Wars Galaxies (NGE or Pre-CU)

⚠️ Before You Start

  • You must own a legal copy of Star Wars Galaxies
  • Antivirus: Add the SWG folder to your antivirus exceptions
  • Admin rights: Run the launcher as Administrator
  • Backups: Back up any existing SWG installation

📥 Download the Launcher

  • 1. Download the SWGReturns Launcher from the Download page
  • 2. Run the installer as Administrator
  • 3. Choose your install directory (default: C:\Program Files\SWG-Returns)
  • 4. Complete the installation

Download the Launcher

📁 Locate Your SWG Client

  • 1. Find your existing SWG installation (e.g., C:\Program Files\SWG)
  • 2. If you don't have one, you'll need a legal copy of the game
  • 3. The launcher will auto-detect your installation
  • 4. You can manually set the path in the launcher settings

🔑 Create Your Account

  • Pre-CU Core3: Register here
  • NGE: Register here
  • You will need a valid email address for account recovery
  • Keep your username and password safe

🚀 Launch the Game

  • 1. Open the SWGReturns Launcher
  • 2. Select your server (Pre-CU or NGE)
  • 3. Click PLAY
  • 4. Enter your account credentials and log in
  • 5. Create your character and start your adventure!
